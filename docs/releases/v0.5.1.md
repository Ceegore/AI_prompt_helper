# Prompt Helper v0.5.1

This release focuses on cross-platform reliability and recovery hardening for the Windows and Linux desktop applications.

## Reliability fixes

- Linux settings now fail closed on unknown future schema versions instead of falling back to an older backup and potentially overwriting newer settings.
- Clean Windows mutations now retire completed ownership claims immediately, so a library can be moved from Windows to Linux without a stale Windows recovery ledger blocking startup.
- If ownership bookkeeping cannot be finalized after a committed Windows replacement, Prompt Helper preserves the committed data and requires restart/recovery instead of rolling it back.
- Malformed legacy durable-temp filenames are rejected safely instead of being able to trigger a parser exception.

## Cross-platform verification

- Added a real Windows → Linux → Windows library roundtrip test with Unicode, nested categories, prompt mutations, canonical bytes, and SHA-256 verification.
- Expanded Windows and Linux crash-recovery, ownership-journal, filesystem-race, settings, and library-store regression coverage.
- Added deterministic headless Avalonia coverage and hardened it against CI teardown deadlocks.

## Release verification

The release pipeline validates:

- Windows full test suite and filesystem/recovery gates.
- Linux core/platform tests and Avalonia desktop startup under Xvfb.
- CodeQL security analysis.
- Self-contained Windows x64 and Linux x64 packages.
- SPDX SBOM data and SHA-256 checksums.
- Windows ZIP, Linux portable tarball, and Debian package.
