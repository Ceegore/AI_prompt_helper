# Prompt Helper v0.5.0

Prompt Helper is now available as a native Linux desktop application while keeping the existing Windows application and library format intact.

## Linux

- New native Avalonia 12 desktop application for Linux x64.
- Self-contained portable `linux-x64` archive; no separate .NET installation is required.
- Debian/Ubuntu `.deb` package with desktop launcher, application icon, and `prompthelper` command.
- Categories, nested navigation, prompt create/edit/copy/move/duplicate/delete, recent copies, settings, custom data root, dark mode, and keyboard shortcuts.
- Uses the same `library.json` and prompt-body files as Windows. Libraries can be moved between Windows and Linux without a format conversion.
- Linux crash-safe atomic writes, compare-and-swap updates, exact filesystem-object identities, ownership journal, startup recovery, and single-instance locking.
- Existing Windows ownership records are preserved and fail closed on Linux when their original filesystem identity cannot be proven.

## Safety and compatibility

- Canonical library JSON retains the historical CRLF byte representation on every OS, so equivalent Windows and Linux libraries have identical canonical bytes and SHA-256 values.
- Linux updates use same-directory staging, file and directory `fsync`, `renameat2(RENAME_NOREPLACE)`, `O_NOFOLLOW`, and `statx` object identity.
- Concurrent or foreign filesystem replacements are preserved instead of being silently overwritten or deleted.
- Corrupt primary library metadata can recover from a valid backup; future-schema metadata is never silently downgraded.
- Unreferenced prompt-body files are preserved for manual inspection.

## Distribution

Release assets include:

- `PromptHelper-v0.5.0-win-x64.zip`
- `PromptHelper-v0.5.0-linux-x64.tar.gz`
- `prompthelper_0.5.0_amd64.deb`
- separate SHA-256 files for every package

Both portable archives contain SPDX SBOM data and per-file SHA-256 checksums. Windows signing remains optional for this hobby project.
