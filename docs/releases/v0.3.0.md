## What's new

- Added a persistent Dark mode switch under **Tools and settings**.
- Theme changes preview immediately and are restored when the dialog is cancelled.
- Windows high-contrast colors always take priority over the light or dark palette.
- Existing v0.2.x settings migrate safely without losing the configured data folder.

## Reliability fixes

- Settings warnings are no longer hidden when the data folder itself is unchanged.
- Restart behavior now follows the actual durable commit result.
- Theme preferences are preserved through data-folder migrations and existing-library switches.
- Commit-critical file verification now handles partial operating-system reads correctly.
- Dark-mode controls, accent foregrounds, and high-contrast text use verified accessible contrast.

## Download

Download `PromptHelper-v0.3.0-win-x64.zip`, extract it, and start `PromptHelper.exe`. This is an unsigned hobby release, so Windows SmartScreen may show a warning on first launch.

The adjacent `.sha256` file contains the SHA-256 checksum for the ZIP.
