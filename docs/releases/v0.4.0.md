# Prompt Helper v0.4.0

This release adds a large, reusable Premades library for common vibe-coding workflows, with an initial emphasis on practical software testing.

## New

- New top-level **Premades** entry.
- Mirrored **Games** and **Tools** planning, implementation, and testing structure.
- 42 bundled prompts for universal testing, game QA, Unity, Windows/WPF/.NET, Web/HTML/PWA, Capacitor/mobile, CLI, and CI.
- Dedicated helpers for bug hunts, regression generation, release readiness, security/privacy, data-loss risks, save/load, performance, localization, accessibility, filesystem safety, mobile lifecycle, and packaging.

## Existing libraries

The bundled pack is installed once when an existing library is opened. Personal categories and prompts are preserved. Matching category paths are reused, interrupted installation can resume safely, and later edits, moves, renames, or deletions of installed premades are respected.

## Distribution

- Portable self-contained Windows x64 ZIP; no .NET installation is required.
- Includes SPDX SBOM and per-file SHA-256 checksums.
- A separate SHA-256 file is published beside the ZIP.
- Unsigned hobby release; no paid signing certificate is required.
