## Highlights

- Redesigned and polished the main interface while preserving the familiar three-card layout.
- Added virtualized, bounded preview loading for much better performance with large prompt libraries.
- Improved keyboard navigation, screen-reader labels, live validation, and Windows High Contrast support.
- Hardened prompt storage, startup recovery, UTF-8 handling, duplication, clipboard access, and path safety.
- Added broader regression, filesystem, recovery, performance, and accessibility test coverage.

## Security and release quality

- Added CodeQL `security-extended`, Dependabot, NuGet vulnerability gates, and npm auditing.
- Release packages now include an SPDX SBOM, SHA-256 checksums, and GitHub build provenance.
- The Windows executable is intentionally unsigned for this free hobby project; Windows may display an
  “Unknown publisher” or SmartScreen warning.

## Installation

1. Download `PromptHelper-v0.2.0-win-x64.zip` below.
2. Extract the ZIP file to any folder.
3. Run `PromptHelper.exe`.

Prompt Helper is self-contained; a separate .NET installation is not required.
